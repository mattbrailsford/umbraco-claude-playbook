# Eval coverage

Generated by `scripts/eval-coverage.sh` from the eval cases in
`plugins/umbraco-devkit/evals/` and the scores in `docs/eval-scores.json`. Don't edit it by hand.

- **Sections covered:** the skill's `## ` sections that at least one eval names in its
  `# covers:` line. A section with no eval is a rule nobody has proven is needed.
- **With / Without:** the latest recorded score (0–100) with the plugin and without it.
  "–" means no run has been recorded.
- **Skill loaded:** in how many recorded with-plugin runs the skill actually loaded.
- Workflow skills have no plain-Claude equivalent, so they show their cases only.
